# dolphin/ — Dolphin pet state + animation assets

On a stock SD card this folder holds `.dolphin.state` — note the leading
dot: it is a hidden file (verified against the firmware source,
`dolphin_state_filename.h` defines `DOLPHIN_STATE_FILE_NAME ".dolphin.state"`).

- **`.dolphin.state`** is **generated by the firmware** — do not hand-edit it.
  It is a binary saved-struct (magic + version + struct, checksum'd) that
  the Dolphin service rewrites on every unlock/level change. Copying a
  stale one over a live device just resets the pet.
- **Custom animations** (classic / ariel / l1… unlock sets) ship as prebuilt
  asset packs *inside* custom firmware (Unleashed / Momentum / Xtreme) and
  install via qFlipper or the mobile app's firmware update — they are not
  SD files you copy by hand.

This folder ships empty on purpose; nothing here needs to be synced.
